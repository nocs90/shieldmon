# Code of Conduct

ShieldMon adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and ideas rather than people,
and keep security discussions constructive and private where disclosure is involved.

**Reporting.** Contact the maintainers privately at `conduct@<project-domain>` (TODO: set a dedicated
address before announcing the project). Reports are
handled confidentially; enforcement follows the Covenant's community impact guidelines
(correction, warning, temporary ban, permanent ban).
